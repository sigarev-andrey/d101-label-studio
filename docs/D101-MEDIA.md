# Размеры и формы этикеток D101

Размер в списке указывается в миллиметрах как ширина поперёк рулона × длина подачи. Общий список для редактора и системного принтера определён в src/label_size.rs.

| Ширина, мм | Длины, мм |
| --- | --- |
| 12 | 22, 30, 40, 75 |
| 12,5 | 109 |
| 13 | 35 |
| 14 | 28, 30, 40 |
| 15 | 30, 50 |
| 20 | 20, 30, 40, 45, 75 |
| 25 | 25, 30, 40, 50, 60 |

Печатающая головка даёт 192 точки при 203 dpi. На рулонах шириной 25 мм растр обрезается симметрично до доступной ширины. Редактор отмечает края на холсте.

## Контуры

Для кабельной этикетки 109 × 12,5 мм узкий хвостик занимает 0–35 мм, широкие половины — 35–72 и 72–109 мм. Линия на 72 мм обозначает сгиб. Поперечная ширина хвостика 6,25 мм и радиусы 0,8 мм приблизительны. Численные длины флажка и хвостика заданы раздельно в каталоге. [Схема кабельной этикетки](https://www.niimbot.uk/cdn/shop/files/NB118Diagram.jpg?v=1787740789&width=2400)

Сохранённые кабельные проекты версии 2 переносятся при открытии. Блоки флажка сдвигаются на 35 мм вправо, блоки хвостика — на 74 мм влево. Блок, пересекающий плечо, сохраняет размер и привязку к границе. Повторное открытие проекта версии 3 сохраняет новые координаты.

Для 20×20 и 25×25 типовой контур круглый. Для 12×40 доступна встроенная маска, для других форматов по умолчанию используется скругление. Контур конкретного расходника может уточняться по прозрачной маске каталога. При печати и экспорте используется альфа-канал. [Публичный шаблон 12×40](https://oss-print.niimbot.com/public_resources/labels/DN202412180005-899eec60b0d012b68aae730d2b2a54fa.png)

## Данные рулона

Расход считывается из RFID. Расширенный ответ также может содержать вместимость. Если известен только лимит печати, приложение запрашивает номинальную вместимость по товарному коду рулона. Остаток равен номинальной вместимости за вычетом расхода. Справочник хранит метаданные расходников, а состояние использования перечитывается с принтера. При отсутствии достоверных данных приложение показывает «Нет данных».

Размер берётся из ответа устройства, когда прошивка передаёт размеры в десятых долях миллиметра. В остальных случаях используется запись каталога с совпадающим товарным кодом и совместимой моделью. После смены рулона можно применить предложенные форму и размер ко всему проекту.
