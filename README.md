# D101 Label Studio

Редактор этикеток для **NIIMBOT D101** на Windows 11 x64. В одном проекте можно собрать несколько макетов, задать число копий каждого и напечатать весь набор по Bluetooth. Для печати из Word, PDF и других приложений доступна системная очередь Windows. Версия **0.1.0** написана на Rust, интерфейс использует WinUI 3.

[Руководство на русском](docs/guide-ru.md) · [English user guide](docs/guide-en.md) · [Размеры и контуры этикеток](docs/D101-MEDIA.md)

## Первый запуск

1. Распакуйте `D101-Label-Studio-win11-x64.zip` и запустите `niimbot-d101.exe`. Редактору нужен **Windows App Runtime 2 x64** версии пакета 2.4.0.0 или выше в ветке 2. [Загрузки Microsoft](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads)
2. Включите Bluetooth в Windows и сам принтер. Откройте **Настройки → Принтер Bluetooth… → Найти Niimbot D101**, выберите устройство и нажмите **Сохранить**. Если рулон распознан, редактор предложит применить его размер и форму к проекту.
3. Добавьте текст или изображение через меню **Добавить**. Кнопка с листом и плюсом в левой колонке добавляет следующую этикетку. Для каждой укажите число копий и отметьте **В наборе**.
4. Откройте **Вид → Предпросмотр**, затем **Печать → Печатать набор**. Команда **Печатать текущую** отправляет только выбранную этикетку с её числом копий.

Язык меняется сразу в меню **Настройки → Язык / Language** и сохраняется после перезапуска. Кнопка **?** в верхней панели открывает справку на выбранном языке. Поиск работает без интернета по заголовкам и тексту всех 13 разделов.

## Серия этикеток из диапазона или списка

Чтобы напечатать «Кабель 001» … «Кабель 010», выберите **Файл → Открыть…** и откройте `examples/generator.json`. В его текстовом блоке уже записано `Кабель {номер}`. [Пример проекта](examples/generator.json)

1. Откройте **Добавить → Генератор этикеток…** и выберите переменную `номер`. В примере задан диапазон от `1` до `10` с шагом `1` и минимумом в три цифры.
2. Проверьте образцы и нажмите **Создать набор**. В проекте появятся десять этикеток, исходный шаблон сохранится с выключенной отметкой **В наборе**.
3. Выберите **Печать → Печатать набор**. Если нужны две копии каждого номера, задайте число копий в генераторе перед созданием набора.

Для произвольных подписей выберите список строк и введите по одному значению на строку. Несколько переменных можно объединить по строкам или перебрать все комбинации. Для импорта готовых текстов и тиражей есть CSV в UTF-8 с заголовком `text,copies`. [Пример CSV](examples/labels.csv)

## Макет и печать

| Что нужно сделать | Как это работает |
| --- | --- |
| Разместить содержимое | Текст, PNG/JPEG, прямоугольники и линии перемещаются по холсту. Размер рамки текста и размер шрифта задаются отдельно. Можно выбрать шрифт Windows, начертание и выравнивание по обеим осям для текста внутри блока и для самого блока на этикетке. |
| Выбрать расходник | В редакторе и системной очереди доступен 21 формат. Размер указан как ширина рулона × длина подачи. У кабельной этикетки 12,5 × 109 мм слева расположен хвостик 35 мм, за ним идут две стороны флажка по 37 мм. |
| Проверить рулон | Верхняя строка показывает модель, заряд, тип этикетки и остаток. Расход поступает с RFID принтера. Для вычисления остатка нужна также вместимость, которую приложение получает от принтера или из каталога по коду рулона. При нехватке данных редактор показывает «Нет данных». |
| Подстроить отпечаток | Печать монохромная, 203 dpi, ширина головки 192 точки. Настраиваются порог для изображений, плотность и поворот на 180°. **Настройки → Калибровка печати…** задаёт вертикальный сдвиг от −16 до +16 точек для выбранного принтера. |
| Управлять тиражом | В одном задании допускается до 1000 экземпляров. Состояние видно в **Печать → Очередь печати**. После потери связи приложение переподключается. Перед повтором прерванного задания сверьте число вышедших этикеток. |
| Сохранить результат | Проект JSON версии 3 хранит макеты, встроенные изображения и настройки генератора. Выбранную этикетку можно экспортировать в PNG с разрешением печати. |

## Печать из других приложений Windows

Запустите D101 Label Studio. Откройте PowerShell **от имени администратора** в распакованной папке и один раз зарегистрируйте очередь.

```powershell
.\scripts\Install-Printer.ps1
```

Выберите **Niimbot D101** в диалоге печати Word или программы просмотра PDF и задайте физический формат этикетки. Драйвер **Microsoft IPP Class Driver** передаёт задание в формате PWG Raster на локальный адрес `127.0.0.1:8631`. Пока идёт печать, оставьте редактор открытым. Для работы без окна можно запустить `.\niimbot-d101.exe --headless` вместо редактора. Удалить системную очередь можно командой `.\scripts\Uninstall-Printer.ps1` из PowerShell с правами администратора.

## English quick start

1. Extract `D101-Label-Studio-win11-x64.zip` on Windows 11 x64. Install Windows App Runtime 2 x64 (package 2.4.0.0 or later in the 2 family) and start `niimbot-d101.exe`.
2. Open **Настройки → Язык / Language** and choose **English**. Menus, dialogs and offline help switch immediately. To switch back, choose **Settings → Language / Язык**.
3. Turn on the D101 and Bluetooth. Open **Settings → Bluetooth printer…**, find the printer, select it and save. Accept the detected stock size when prompted.
4. Add blocks, set copies and select the labels to include. Choose **View → Print preview**, then **Print → Print set**. For numbering or lists of names, place a variable such as `{name}` in a text block and open **Insert → Label generator…**.

Use the **?** button to search the offline guide. It also covers print calibration and setting up the Windows queue. [Read the English guide](docs/guide-en.md)

## Сборка из исходников

На Windows x64 откройте Developer PowerShell с Rust MSVC, инструментами сборки C++ и компилятором ресурсов Windows SDK. Выполните команды из корня репозитория.

```powershell
cargo test --all-targets --locked
cargo clippy --all-targets --locked -- -D warnings
.\scripts\Build.ps1 -UseSystemCargo
```

Для сборки переносимым набором GNU в обычном PowerShell выполните следующие команды. Первая скачивает инструменты в папку `.tools` внутри проекта.

```powershell
.\scripts\Bootstrap.ps1
.\scripts\cargo.ps1 test --all-targets --locked
.\scripts\Build.ps1
```

Готовый архив для Windows появится в `dist/D101-Label-Studio-win11-x64.zip`. В него входят программа, оба руководства, справочник размеров, примеры, скрипты установки и удаления очереди и лицензии. Чтобы получить архив исходников текущего коммита, выполните `git archive --format=zip --output=D101-Label-Studio-source.zip HEAD`.

## Локальные данные и симуляция

Настройки, выбранный принтер, калибровка, черновик, очередь печати и кэш каталога хранятся в `%LOCALAPPDATA%\NiimbotD101`. Макеты и изображения обрабатываются на компьютере. При обращении к каталогу NIIMBOT приложение передаёт товарный код расходника.

Для работы без принтера запустите `.\niimbot-d101.exe --simulate`. Симулятор использует профиль `%LOCALAPPDATA%\NiimbotD101-Simulation`, порт `18631` и сохраняет изображения заданий в подпапке `simulated`.
